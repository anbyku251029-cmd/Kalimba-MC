# 🎙️ Kalimba-MC STEP 02-B: 어린이 연주 녹음 스튜디오 및 WAV 파일 내보내기 시스템 완료 보고서

## 1. 개요
- **프로젝트명**: 우리 아이 칼림바 음악 교실 (Kalimba-MC)
- **작업 단계**: STEP 02-B — 어린이 연주 녹음 스튜디오 및 WAV 파일 내보내기 시스템 구축
- **기술 환경**: React 19, TypeScript, Vite 8, Tailwind CSS v4, Web Audio API, Canvas/SVG, Pointer Events API
- **대상 기기**: PC(마우스·키보드 1~7번 건반), 태블릿/스마트폰(정밀 멀티터치)

---

## 2. 주요 구현 기능 요약

### 1) 🎙️ 직관적인 대형 컨트롤 UI (어린이 맞춤형)
- **6가지 명확한 상태 머신**: `READY` (준비) ➔ `RECORDING` (녹음 중) ➔ `PAUSED` (잠시 멈춤) ➔ `STOPPED` (완료) ➔ `PLAYING` (다시 듣기) ➔ `EXPORTING` (WAV 저장 중)
- **상태별 시각적 피드백**:
  - 녹음 중: 빨간색 펄스 링과 실시간 경과 시간 스톱워치(`MM:SS.s`), 현재까지 연주된 음표 개수 카운터
  - 재생 중: 초록색 반짝임 애니메이션 및 현재 재생 시점 인디케이터
- **원클릭 액션 버튼**:
  - `녹음 시작` / `잠시 멈춤` / `녹음 끝내기` / `다시 듣기` / `WAV 다운로드` / `새로 녹음`

### 2) ⏱️ 고정밀 단조 증가 타임스탬프 기록
- 브라우저의 가변적인 이벤트 루프 지연이나 시스템 시간 변경의 영향을 받지 않도록 `AudioContext.currentTime`을 기준으로 상대 경과 시간(`startTimeMs`)을 밀리초 단위로 기록합니다.
- **30ms 디바운스 필터**: 건반을 누를 때 손가락의 미세한 흔들림이나 터치 바운스로 인한 중복 연타 방지.
- **45ms 화음 그룹화**: 45ms 이내에 연달아 입력된 여러 음표를 단일 `groupId`로 묶어 아름다운 화음(2화음, 3화음)으로 기록 및 보존합니다.

### 3) 🎼 실시간 롤링 타임라인 & 음표 카드
- 어린이가 건반을 누를 때마다 화면 중앙의 타임라인에 계이름(도, 레, 미...), 숫자 악보(1, 2, 3...), 시간차가 예쁜 카드로 즉시 생성되어 가로로 스크롤됩니다.

### 4) 🎵 내장 오디오 재생 엔진 즉시 청취
- 녹음 완료 후 `[다시 듣기]` 버튼을 누르면 연주했던 속도와 타이밍 그대로 칼림바 오디오 엔진을 통해 재생됩니다.
- 현재 선택된 칼림바 음색 모드(비조화 배음 물리 모델링)와 어쿠스틱 잔향(Reverb)이 그대로 적용됩니다.

### 5) 💾 표준 16-bit PCM Linear Stereo 44.1kHz WAV 내보내기
- `OfflineAudioContext`를 통해 녹음된 모든 음표를 44.1kHz 고음질 스테레오 버퍼로 초고속 오프라인 렌더링.
- 연주 마지막 음표 뒤에 **1.8초의 자연스러운 리버브 테일(Reverb Tail)**을 부여하여 잔향이 뚝 끊기지 않고 부드럽게 감쇠됩니다.
- 표준 RIFF/WAVE 헤더를 바이너리 인코딩하여 스마트폰, 태블릿, PC 어디서나 재생 가능한 순수 `.wav` 파일로 즉시 다운로드됩니다.

### 6) 📝 숫자 악보(Simple Notation) 자동 변환
- 연주된 음표 간의 시간차를 분석하여 4분음표, 늘임표(`-`, `--`), 마디선(`|`)을 정규화하여 Kalimba-MC 표준 숫자 악보로 변환 및 화면 미리보기를 제공합니다.

## 3. 화면 구성 및 사용 방법

1. **곡 선택 화면 (`SongSelectScreen`)**:
   - 우측 상단 툴바에 새로 추가된 **`[🎙️ 나만의 녹음실]`** 버튼 클릭 (핑크-로즈 그라데이션 및 펄스 효과).
2. **녹음실 화면 (`RecordingStudio`)**:
   - **`[🔴 녹음 시작]`** 버튼 클릭 후 하단 17음 가상 칼림바 건반(또는 키보드 1~7번 키)을 자유롭게 연주.
   - 연주 중 **`[⏸️ 잠시 멈춤]`** 또는 **`[⏹️ 녹음 완료]`** 클릭.
   - 녹음이 끝나면 **`[▶️ 다시 듣기]`**로 연주 확인.
   - **`[💾 WAV 파일로 저장]`** 버튼을 클릭하면 `내칼림바연주_YYYYMMDD_HHMM.wav` 파일이 내 컴퓨터/스마트폰에 즉시 저장됩니다.
   - 생성된 숫자 악보를 복사하여 새로운 찬송가나 나만의 동요로 등록할 수 있습니다.
