## 3. 구현된 검사 규칙 체계 (규칙 A ~ G)

| 규칙 분류 | 검사 항목 | 판정 기준 및 오류 코드 |
| :--- | :--- | :--- |
| **규칙 A: 기본 곡 정보** | 곡 ID, 제목, 난이도, BPM, 박자표, 음표 배열 존재 여부 | 누락 또는 형식 오류 시 `FAIL` (`MUSIC_MISSING_ID`, `MUSIC_MISSING_TITLE`, `MUSIC_DUPLICATE_ID`, `MUSIC_INVALID_BPM`, `MUSIC_INVALID_TIME_SIGNATURE`, `MUSIC_EMPTY_NOTES`) |
| **규칙 B: 음표 데이터** | 양수 길이(`duration > 0`), 유한 숫자(`isFinite`), 미지원 기호 여부 | 0 이하, 음수, NaN 등 발생 시 `FAIL` (`NOTE_INVALID_DURATION`) |
| **규칙 C: 리듬 및 음표 길이** | 4분음표 1.0비트 기준 일관성, 전체 연주 시간 계산, 쉼표 시간 누적 | `(totalBeats / BPM) * 60`으로 계산, 쉼표 누적 비트 정확 보존 |
| **규칙 D: 마디 및 박자표** | 마디선(`\|`) 기준 마디별 박자 합계 일치 여부 | 박자표와 마디 박자 불일치 시 `REVIEW` (`RHYTHM_MEASURE_MISMATCH`), 못갖춘마디는 정상 참작 |
| **규칙 E: 칼림바 음역** | 17음 C Major (C4~E6) 지원 건반 17개 인덱스(0~16) 매핑 | 미지원 음(반음 샵/플랫 또는 음역 이탈) 발견 시 `FAIL` (`PITCH_OUT_OF_RANGE`) |
| **규칙 F: 파서 일관성** | 숫자보, 한글 계이름, 높은음, 늘임표, 8분음표, 가사 결합 파싱 | 파싱 전후 음표 수 및 길이 보존 검증 |
| **규칙 G: 재생과 데이터 집계** | `totalNotes`에 쉼표 제외 여부 및 실제 연주 블록 개수 일치 | 연주음(`playableNotes`)과 쉼표(`restNotes`) 명확히 분리 집계 |

## 6. 발견된 REVIEW 문제 대표 사례 및 미수정 사유

### 대표 사례:
1. **[초급] 산토끼 (`beginner-6`):**
   - 4/4 박자곡이나, 일부 마디가 3박자로 채보되어 총 3개 마디에서 불일치 감지.
2. **[초급] 곰 세 마리 (`beginner-7`):**
   - 4/4 박자곡이나, 붓점 단순화 편곡으로 인해 4개 마디에서 박자 차이 감지.
3. **[중급] 브람스 자장가 (`inter-26`):**
   - 3/4 박자곡이나, 악보 텍스트의 마디선(`|`) 위치가 4박 단위로 잘못 나뉘어 12개 마디 불일치 감지.
4. **[고급] 그린슬리브스 (`adv-20`):**
   - 6/8 박자곡(마디당 3비트 기준)에서 4분음표와 점4분음표 길이 표기 차이로 5개 마디 불일치 감지.

### 자동 수정하지 않은 사유:
- 최우선 보호 규칙 제9조("음악적으로 의심스러운 음표를 자동으로 교체하지 않는다") 및 제10조("원곡 악보가 없는 경우 원곡 일치 여부를 자동으로 PASS 처리하지 않는다")에 따라, 검증 엔진이 임의로 음표를 늘리거나 줄이지 않고 정확한 마디 번호와 차이 비트(`diff`)를 기록하여 향후 STEP 01-E/F에서 신뢰할 수 있는 공인 악보를 바탕으로 정밀 교정하도록 안전하게 분류하였습니다.
