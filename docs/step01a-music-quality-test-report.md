## 3. 자동 검사와 수동 검토의 구분

- **자동 검사 완료 항목 (PASS):**
  - 곡 ID, 제목, 박자표, BPM, 난이도 데이터 존재 여부
  - 모든 음표의 양수 duration (> 0) 및 유효한 pitch
  - 17키 칼림바 C Major 음역 내 완전 수용 여부
  - 첫 음 재생 시작 타이밍(-2.0 예비박) 및 폭포수 도달 시점
  - 웹 오디오 클리핑 방지 및 정지 시 잔향 정리
- **수동 검토 필요 항목 (REVIEW):**
  - 원곡 특유의 붓점 리듬 반영 여부 (동요 편곡 시 초보자 난이도 고려 필요)
  - 2절 이상의 긴 곡 도입 시 지루함 방지를 위한 프레이즈 구성
  - 실제 스피커/이어폰 청취 시의 음색 선호도 (기본 / 맑은 / 부드러운)
