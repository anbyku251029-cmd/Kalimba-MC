# 📝 Kalimba-MC 음악 품질 개선 변경 이력 (Change Log)

- **작업 일자**: 2026-10-21
- **적용 단계**: STEP 01-A ~ STEP 01-I

---

## 1. 수정된 모듈 및 파일 목록

1. **`src/utils/musicValidator.ts` (신규 생성)**:
   - 곡 데이터 품질 검증기 모듈 구현.
   - 메타데이터 검증, 17키 음역 적합성, 마디별 박자 합계, 재생 시간 자동 계산, PASS/REVIEW/FAIL 판정 엔진 탑재.
2. **`src/utils/audioEngine.ts` (품질 개선)**:
   - `KalimbaTimbreMode` ('default' | 'bright' | 'soft') 3대 음색 모드 지원.
   - `DynamicsCompressorNode` 추가로 다성부 클리핑 방지.
   - 앰비언스 리버브 공간감 효과 및 마스터 볼륨 조절 구현.
   - 사운드 설정 로컬스토리지(`kalimba_audio_settings_v1`) 영구 저장.
3. **`src/components/SoundSettingsModal.tsx` (신규 생성)**:
   - 음색 선택(샘플 화음 즉시 시연), 볼륨 슬라이더, 리버브 토글, 설정 초기화 모달 UI.
4. **`src/components/SongSelectScreen.tsx` (기능 확장)**:
   - 상단 `[🎛️ 사운드 / 음색 설정]` 버튼 연결.
   - 각 곡 카드에 폭포수 진입 전 `[🔊 미리 듣기 / ⏹️ 정지]` 버튼 탑재.
   - 총 음표 수 및 실제 계산된 연주 시간(예: `⏱️ 24초`, `⏱️ 49초`) 정밀 표기.
5. **`src/data/songsAdvanced.ts` (악보 교정)**:
   - `adv-10` (엘리제를 위하여): 3/4박자 기준 3번, 10번 마디 박자 초과(4박) 오류를 3박(`2' 1' 6`)으로 정합 교정.
6. **`src/data/hymns.ts` (악보 교정)**:
   - `hymn-305` (나 같은 죄인 살리신): 3/4박자 기준 마디별 박자 불일치(5박)를 새찬송가 305장 원곡 부점/8분음표 리듬으로 정밀 재채보 완료.
   - `hymn-563` (예수 사랑하심은): 후렴구 10, 12, 14마디의 1박자 누락을 4/4박자 원곡 규격으로 정합 교정 완료.
7. **`scripts/runQualityAudit.ts`, `scripts/runPilotAudit.ts`, `scripts/runPitchAudit.ts` (신규 생성)**:
   - CLI 환경에서 전체 곡 및 대표곡의 음악적 무결성을 즉시 검증하는 자동화 스크립트 구축.

## 2. 변경 전후 비교 요약

| 검토 항목 | 변경 전 | 변경 후 |
| :--- | :--- | :--- |
| **음향 엔진** | 단일 고정 음색, 볼륨 조절 불가, 리버브 부재 | 3가지 전문 음색(기본/크리스탈/목재), 볼륨 조절, 리버브, 컴프레서 완비 |
| **미리 듣기** | 없음 (반드시 폭포수 게임을 시작해야 소리 청취 가능) | 곡 선택 화면에서 카드별 즉시 미리 듣기 및 원클릭 정지 지원 |
| **연주 시간 표시** | 정적 메타데이터(3~6분)만 표시되어 실제 곡 길이와 괴리 | 실제 음표 duration과 BPM 기반 계산 시간(예: ⏱️ 38초) 정확히 표기 |
| **엘리제를 위하여** | 3/4박자에 4박 마디가 존재하여 리듬 정합성 깨짐 | 마디별 정확한 3.0박자로 교정 완료 |
| **나 같은 죄인 살리신** | 3/4박자 곡에 마디당 5박자가 들어가 부점 리듬 훼손 | 새찬송가 305장 정밀 채보(8분음표/점음표 반영)로 16마디 완벽 정합 |
| **예수 사랑하심은** | 후렴구 3개 마디에서 1박자씩 누락 (3박 마디 발생) | 4/4박자 16마디(총 64박자) 완벽 정합 교정 |
| **음악 품질 검증 체계** | 자동 검증 도구 없음 | `musicValidator.ts` 및 자동화 스크립트로 110곡 상시 검증 가능 |

## 3. 향후 우선순위 권장 과제

1. **나머지 곡들의 부점/8분음표 리듬 점진적 고도화**:
   - 파일럿 9곡에서 성공적으로 검증된 박자 정합 체계를 바탕으로, 산토끼, 곰 세 마리 등 나머지 동요들의 8분음표 리듬을 하나씩 정밀 검토 및 교정.
2. **다성부(화음) 데이터 규격 확장**:
   - 칼림바 양손 동시 타건(2음 화음, 3음 글리산도)을 지원하는 다성부 타임스탬프 인터페이스 연구.
