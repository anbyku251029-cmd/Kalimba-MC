## 3. 마디 경계 판정 방식 및 메타데이터 추출 엔진

`src/utils/measureParser.ts`를 신규 구현하여 임의 추측 없이 악보 원본을 기반으로 마디 메타데이터를 정밀 추출하였습니다:

1. **1차 판정 근거 (`source: 'BAR_DELIMITER'`)**
   - 악보의 `rawNotation` 문자열에 포함된 `|` 구분자를 파싱하여 각 마디별 음표 그룹을 분할.
2. **박자표 기대 비트 일치성 검증 (`expectedBeats`)**
   - 4/4 박자: 4.0비트
   - 3/4 박자: 3.0비트
   - 2/4 박자: 2.0비트
   - 6/8 박자: 3.0비트 (점4분음표 2개 기준)
   - 각 마디의 비트 합계(`totalBeats`)가 기대 비트와 일치(오차 0.05 이내)하면 `PASS`, 불일치 시 `REVIEW`로 판정.
   - 단, 첫 마디가 짧은 경우 못갖춘마디(픽업 마디)로 참작하여 정상 처리.
3. **폴백 판정 근거 (`source: 'TIME_SIGNATURE_CALCULATED'`)**
   - `|` 기호가 없는 사용자 악보의 경우, 박자표 비트 합계 단위로 신뢰성 있게 자동 분할하되 불완전하면 `REVIEW` 표시.
4. **전곡 110곡 전수 검사 결과**
   - 카탈로그 110곡 전수 대상에서 총 **1,145개 마디**가 단 1건의 오류 없이 100% 정상 추출됨.

## 4. 마디 범위 선택 UI 구현 결과 ([StepLearningModal.tsx](file:///c:/Users/anbyo/OneDrive/바탕%20화면/Work/Kalimba-MC/src/components/StepLearningModal.tsx))

어린이와 학부모가 직관적으로 조작할 수 있는 마디 선택 인터페이스를 완성하였습니다:

1. **시작 마디 & 마지막 마디 선택기**
   - 시작 마디(1 ~ N)와 종료 마디(시작 ~ N)를 드롭다운 및 스텝 방식으로 선택.
   - 시작 마디가 종료 마디보다 커질 수 없도록 실시간 제약 로직 적용.
2. **원터치 빠른 마디 프리셋**
   - `전체 마디 (1~N마디)`: 곡 전체를 구간으로 설정
   - `앞부분 (1~4마디)`: 인트로 및 전반부 테마 집중 연습
   - `중간 (5~8마디)`: 클라이맥스 및 도약 구간 연습
   - `끝부분 (9~N마디)`: 엔딩 마무리 구간 연습
3. **구간 정보 실시간 뱃지**
   - 선택된 마디 수, 총 음표 수, 총 연주 비트 수를 카드에 실시간 표시.

## 5. 3단계 구간 연습 구현 결과

선택된 마디 범위 `[startMeasure, endMeasure]`를 기준으로 3단계 연습 시스템을 구축하였습니다:

- **1단계: 선택 마디 1회 먼저 듣기 (`SECTION_LISTEN`)**
  - 선택한 마디의 첫 음표부터 마지막 음표까지 정확히 1회 재생하고 자동 정지.
  - 선택 범위 밖의 음표는 절대 재생되지 않음.
- **2단계: 천천히 따라 하기 (`SECTION_SLOW`)**
  - 50%(느림), 70%(보통 학습), 100%(원곡) 속도 배율을 지원하며, 애니메이션과 음표 길이가 비례 스케일링됨.
- **3단계: 구간 반복 연습 (`SECTION_REPEAT`)**
  - 반복 횟수를 **1회 / 3회 / 5회** 중 선택 가능 (기본 3회).
  - 각 회차 완료 후 **0.6초의 자연스러운 호흡 간격**을 제공하여 어린이가 손가락 위치를 재정비할 시간 보장.
  - 현재 반복 진행 상황 표시: `반복 연습 멈추기 (2 / 3회)`.
  - 목표 횟수 달성 시 축하 멘트와 함께 학습 기록(누적 시간 및 횟수) 정직하게 저장.
