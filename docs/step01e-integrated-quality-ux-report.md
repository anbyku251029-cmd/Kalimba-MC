## 2. STEP 01-E 작업 목표 및 범위

1. **4중 음악적 일관성 검증 (Quad-consistency)**
   - 악보 음표(Note) → 17음 칼림바 물리 건반 매핑(Key Index) → Web Audio API 발음 주파수(Hz) → 화면 폭포수 및 건반 시각 효과(Rendering)의 1:1 완벽 사상 검증
2. **어린이 학습자 중심의 UX 대폭 개선**
   - 곡 선택 화면의 버튼 명확화: `먼저 듣기`(소리 미리듣기), `연습 시작하기`(첫 음부터 연주)
   - 검색 빈 상태(Empty State) 개선: 검색 결과 0개 시 친절한 어린이 안내 멘트 및 원터치 전체 곡 복구 버튼 제공
   - 원클릭 속도 프리셋 제공: 손가락 조작이 미숙한 어린이를 위한 `🐢 천천히 (70%)`, `🐰 보통 (100%)`, `🚀 빠르게 (120%)` 프리셋 버튼 도입
3. **재생 엔진 라이프사이클 통합 검증**
   - 초기 예비박(-2.0 beats) → 재생 → 일시정지 → 재개 → 처음부터 다시하기 → 곡 완주 트리거의 상태 머신 완전성 검증
4. **전곡 데이터 및 사용자 데이터 100% 무결성 보호**
   - 초급 30곡, 중급 30곡, 고급 30곡, 기본 찬송가 20곡 (총 110곡)의 원본 데이터 불변 보존
   - 사용자 브라우저 localStorage 찬송가 편집 데이터 보존

## 5. Web Audio API 오디오 엔진 재생 품질 검증

1. **맑고 자연스러운 칼림바 물리 음색 합성**
   - **피치 디플렉션 (Pitch Deflection)**: 건반을 강하게 튕길 때 쇠막대의 초기 장력 증가로 약 +1.5~2.5Hz 일시 상승 후 8~12ms 내 기음으로 안착하는 미세 물리 현상 재현.
   - **비조화 고차 배음 (Inharmonic Overtones)**: 칼림바 고유의 5.4배 쇠막대 클램프 배음을 오실레이터로 합성하여 투명하고 청아한 금속성 공명 구현.
   - **차등 감쇠율 (Differential Decay)**: 저음부(C4~G4)는 약 2.4초간 깊고 풍성하게 서스테인이 유지되고, 고음부(C6~E6)는 약 0.65초간 맑고 또랑또랑하게 감쇠.
2. **클릭 노이즈 완전 제거**
   - 2.5ms의 선형 어택 엔벌로프 및 0보다 큰 지수 감쇠 타겟(`0.0001`)을 적용하여 팝/클릭 잡음이 발생하지 않음.
3. **사운드 모드 지원**
   - 기본 칼림바(`default`), 맑은 크리스탈(`bright`), 포근한 목재 울림(`soft`)의 3가지 음색 프리셋 및 공간감 잔향(리버브) 실시간 토글 지원.

## 6. 연주 타이밍 및 애니메이션 동기화 검증

- **예비박 동기화**: 곡 선택 후 진입 시 `INITIAL_LEAD_IN_BEATS`(-2.0박자) 동안 상단에서 폭포수 음표가 여유 있게 낙하하여 어린이가 건반 위치를 미리 인지하고 준비할 수 있음.
- **타격선(Strike Line) 일치**: 비트 시간이 `0.0`에 도달하는 순간 정확히 타격선(54% Y좌표)과 폭포수 알약 중심이 교차하며 해당 물리 건반에 글로우 발광 효과 및 소리가 출력됨.
- **여운 보존 및 완주 모달**: 마지막 음표가 연주되자마자 모달이 뜨는 오류를 차단하고, `timeline.audibleEndBeat`까지 마지막 음이 완전히 울려 퍼진 뒤에 완주 모달이 나타남.

## 7. 어린이 학습 UX 개선 상세 내역

### A. 곡 선택 화면 (`SongSelectScreen.tsx`)
1. **버튼 목적의 명확화**
   - 기존의 혼란스러울 수 있는 버튼을 `[먼저 듣기]`(스피커 아이콘, 앞 16음 미리 재생)와 `[연습 시작하기]`(재생 아이콘, 첫 음부터 연주 화면 진입)로 명확히 분리.
2. **검색 빈 상태(Empty State) 어린이 안내 뷰 신설**
   - 검색 결과가 0개일 때 빈 카드 대신 커다란 돋보기 아이콘(`🔍`)과 함께 친절한 안내 문구 표시:
     > "앗! 찾으시는 곡이 없어요. 다른 제목으로 검색해 볼까요?"
   - 원클릭 `[검색어 지우기]` 버튼 및 `[모든 곡 보기 (110곡)]` 버튼을 제공하여 어린이가 손쉽게 목록으로 복귀할 수 있도록 지원.
3. **가독성 및 명도 대비 강화**
   - 카드 내 총 음표 수, 연주 시간, BPM 태그의 배경 명도를 높여 어린이 및 보호자가 한눈에 곡 정보를 알아볼 수 있도록 개선.

### B. 게임 연주 화면 (`KalimbaGameWaterfall.tsx`)
1. **어린이용 원클릭 속도 프리셋 버튼 도입**
   - 미세 조작이 힘든 저연령 어린이를 위해 슬라이더 외에 원터치 프리셋 버튼 3종 추가:
     - 🐢 **천천히 (70%)**: 처음 배우거나 빠른 곡을 차근차근 연습할 때
     - 🐰 **보통 (100%)**: 원곡 템포 그대로 자연스럽게 연주할 때
     - 🚀 **빠르게 (120%)**: 곡에 완전히 익숙해져 신나게 연주할 때
2. **칭찬 피드백 배지 애니메이션 유지**
   - 연주 성공 시 화면 우측에 `⭐ 잘했어요!`, `최고예요!`, `멋져요!` 칭찬 팝업이 나타나 학습 동기 부여.

## 8. 템포 조절(50%~150%) 및 프리셋 동작 검증

- **원곡 데이터 불변성 검증**:
  - 연습 속도를 50%, 70%, 120%, 150%로 변경하더라도 악보 객체의 `song.tempoBpm`은 절대 변조되지 않음.
- **비례 타이밍 계산 검증**:
  - `effectiveBpmMultiplier = speedPercent / 100` 공식에 따라, 70% 설정 시 1박의 연주 시간(`beatDurationSeconds`)이 100% 대비 정확히 1.428배 증가하여 여유 있는 연주 템포가 구현됨.

## 15. 발견된 한계점 및 향후 개선 과제

1. **실제 물리 녹음 음원(샘플링) 부재의 한계**
   - 현재는 Web Audio API의 물리 모델링(배음 합성, 어택 노이즈, 공진 필터)으로 매우 맑은 음색을 구현했으나, 실제 목재 바디의 미세한 공명 질감(Wood Grain Resonance)을 100% 재현하는 데는 수학적 한계가 존재함. 차기 단계에서 고음질 무손실 칼림바 샘플링 오디오 지원 검토 가능.
2. **저연령 어린이를 위한 음성 안내(TTS) 추가 검토**
   - 아직 한글을 완전히 떼지 못한 5~6세 유아를 위해 "도 건반을 눌러보세요!", "참 잘했어요!" 음성 가이드 추가 고려 가능.
