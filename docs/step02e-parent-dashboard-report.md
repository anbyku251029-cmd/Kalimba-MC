# 📈 Kalimba-MC STEP 02-E: 학부모 학습 대시보드 기능 및 지표 정의서

## 1. 개요
학부모 대시보드는 가정에서 부모님이 자녀의 칼림바 연습 시간, 완주 곡 수, 요일별 연습 습관을 직관적으로 파악할 수 있도록 돕는 보호자 전용 화면입니다.

화면 타이틀: **`학부모 학습 대시보드`** (보호자 전용 배지 부착)

---

## 2. 핵심 지표 정의 (Core Metrics)

| 지표명 | 계산 기준 | UI 표시 예시 | 목적 및 의의 |
| :--- | :--- | :--- | :--- |
| **오늘 연습** | 오늘($Asia/Seoul$) 발생한 모든 세션의 순수 연습 초 합계 | `15.5 분` (930초) | 오늘의 연습량 즉시 확인 |
| **이번 주 연습** | 이번 주 월요일 00:00부터 오늘까지의 연습 시간 합계 | `48.2 분` (7일 중 4일 출석) | 주간 학습 습관 형성 여부 |
| **이번 달 연습** | 이번 달 1일 00:00부터 오늘까지의 연습 시간 합계 | `120.5 분` (누적 24회) | 월간 지속적인 관심도 확인 |
| **완주한 곡** | 한 번 이상 끝까지 연주에 성공한 **고유 곡 수** | `12 곡` (총 완주 18회) | 동일 곡 반복과 다양한 곡 도전을 분리 집계 |

> [!IMPORTANT]
> **고유 완주 곡 수 vs 총 완주 횟수 분리**:
> 아이가 한 곡을 즐겁게 10번 완주했다고 해서 '10곡을 배웠다'고 오해하지 않도록, `고유 곡 수: 1곡`과 `총 완주 횟수: 10회`를 화면에 명확히 구분하여 표기합니다.

## 3. 주간 학습 그래프 (최근 7일 추이)

외부 차트 라이브러리(Chart.js, Recharts 등) 없이 **순수 CSS Grid와 SVG 기반의 초경량 반응형 막대 차트**로 구현되었습니다.
- **기간**: 오늘을 포함한 최근 7일 (과거 6일 ~ 오늘)
- **표시 단위**: 분(m) 단위 표시 (0분인 날은 0 표시)
- **강조**: 오늘 날짜 바는 형광 시안(Cyan) 그라데이션 및 펄스 글로우 효과 적용
- **최대 스케일**: 주간 최장 연습 시간에 맞춰 5분 단위 올림(Ceil) 자동 스케일링

## 4. 최근 활동 목록 & 곡별 통계

### 1) 최근 연습 기록 탭
- 최신 시간순 50건 표시
- **상태 배지**: `완주 🏆` (초록색) vs `연습` (주황색)
- **정보**: 곡명, 난이도, 실제 연습 초, 연주 시각, 점수 및 정확도(%)
- **필터**: `[전체]`, `[완주곡]`, `[연습중]` 3가지 원클릭 필터링
- **개별 삭제**: 잘못 측정되었거나 불필요한 기록을 부모님이 직접 삭제 가능

### 2) 곡별 학습 통계 탭
- 곡별 총 연습 횟수, 총 연습 시간(분), 완주 횟수, 최고 점수 표시
- 아이가 어떤 곡에 특히 흥미를 느끼고 깊이 몰입하는지 파악 가능
