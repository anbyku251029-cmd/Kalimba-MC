## 1. 작업 개요 및 핵심 목표 달성

본 단계는 기존의 화면 터치/마우스/키보드 연주 방식에 더하여, **어린이가 손에 쥔 실제 17음 칼림바 악기를 직접 튕길 때 마이크로 소리를 듣고 실시간으로 기본 주파수(F0)와 음높이를 판별하여 워터폴 게임에서 정답을 판정하고 점수/콤보를 부여하는 기능**을 구현한 작업입니다.

### 4대 핵심 원칙 준수 결과
1. **기존 프로그램 완전 보존**:
   - 111개 전 곡(초급 30, 중급 30, 고급 30, 찬송가 21) 및 사용자 커스텀 곡, STEP 03-A 화음·양손 워터폴 시스템 100% 정상 작동.

   - 기본 입력 모드는 `touch` 모드이며, 마이크 권한이 없거나 거부되어도 기존 화면 연주는 전혀 지장 없이 작동.
3. **어린이 프라이버시 보호 (COPPA 및 온디바이스 원칙)**:

4. **측정 데이터의 정직성**:
   - 실제 물리 칼림바 하드웨어 마이크 테스트는 CI/터미널 환경 특성을 정직하게 `NOT_TESTED`로 기록하고, 수학적 합성 신호 테스트로 100% 검증.

## 2. 주요 개발 내역 및 아키텍처

### 1) 실물 칼림바 마이크 판정 엔진 (`src/utils/acousticKalimbaJudge.ts`)
- **센트(cents) 오차 정밀 공식**:
  $$\text{cents} = 1200 \times \log_2\left(\frac{f_{\text{detected}}}{f_{\text{target}}}\right)$$
- **판정 등급 및 허용 오차**:
  - `PERFECT`: $|\text{cents}| \le 35$ (칼림바 건반의 정확한 타격)
  - `GREAT`: $35 < |\text{cents}| \le 70$ (약간 빗나갔으나 유효한 타격)
  - `RETRY`: $|\text{cents}| > 70$ 또는 다른 음표 타격
  - `SILENCE`: $\text{RMS} < 0.015$ (배경 소음 이하 무음 필터링)
  - `WAITING`: 신뢰도(Confidence) $< 0.65$ (불안정한 배음/잡음 필터링)
- **쿨다운(Debounce) 메커니즘**:
  - 칼림바 특유의 잔향(Sustain)으로 인해 한 번 튕겼을 때 다중 타격으로 오인되는 것을 방지하기 위해 `cooldownMs: 320ms` 디바운싱 적용.

### 2) 어린이용 마이크 인디케이터 UI (`src/components/MicrophoneAcousticIndicator.tsx`)
- 워터폴 게임 상단에 실시간 음량 바(RMS 0~100%), 감지된 음표(예: C4, G4), 센트 오차 게이지 바(-50¢ ~ +50¢), 판정 뱃지(PERFECT, GREAT 등) 및 친절한 안내 문구 표시.

### 3) 실물 칼림바 마이크 튜너 및 진단기 (`src/components/MicrophoneTunerModal.tsx`)
- 곡 선택 화면 상단에 `[🎼 칼림바 튜너]` 버튼을 신설하여, 연습 전 실제 칼림바의 17개 건반 조율 상태를 진단하고 특정 건반 집중 튜닝 기능 제공.

### 4) 워터폴 게임 화면 연동 (`src/components/KalimbaGameWaterfall.tsx`)
- 헤더에 `입력 방식: 👆 터치 | 🎤 실물` 스위치 제공.
- 실물 모드 활성화 시 현재 히트라인 부근의 `targetNote`와 마이크 입력 음정을 실시간 비교하여, 일치 시 자동으로 `handleUserNoteInput`을 호출하여 콤보, 점수, 캐릭터 반응 연동.
