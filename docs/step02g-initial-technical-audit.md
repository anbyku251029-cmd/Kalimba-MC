## 3. 핵심 기술 과제 및 비교 분석

### 3.1. 사람의 허밍(음성) 분석의 기술적 특성
1. **풍부한 배음 구조**: 순수 사인파와 달리 사람의 성대 진동은 기본 주파수(F0) 외에 2배, 3배 고조파(Harmonics) 에너지가 강력하여 단순 FFT 피크 검출 시 한 옥타브 높은 음으로 오인(Octave Doubling)되기 쉽습니다.
2. **모호한 음표 경계(Legato & Slur)**: 발음("타", "쿵")이 뚜렷하지 않은 허밍("음~", "라~")은 음표 사이의 어택(Onset) 에너지가 완만하여 시작과 끝을 구분하기 어렵습니다.
3. **피치 드리프트(Pitch Drift)와 바이브레이토**: 초보 어린이는 호흡과 음정이 흔들리며, 인접한 반음 사이를 미끄러지듯 이동(Portamento)합니다.
4. **음역대 차이**: 성인 남성이나 어린이가 편안하게 허밍하는 음역(C3~B3, 130~250Hz)은 칼림바 최저음인 C4(261.63Hz)보다 1옥타브 낮습니다.

### 3.2. 채보 방식 비교 (로컬 DSP vs 클라우드 AI API)

| 평가 항목 | 방안 A: 브라우저 로컬 DSP (YIN + RMS) | 방안 B: 클라우드 AI API (외부 엔드포인트) |
|---|---|---|
| **오프라인 지원** | **완벽 지원 (100% PWA 연동)** | **불가 (인터넷 필수)** |
| **개인정보 보호** | **최상 (음성이 브라우저 외부로 유출되지 않음)** | 보통~취약 (어린이 음성 외부 서버 전송 규제 리스크) |
| **처리 지연(Latency)** | **즉각적 (3초 녹음 기준 50ms 이내 처리)** | 지연 발생 (네트워크 업로드 및 추론 2~5초 소요) |
| **운영 비용** | **0원 (서버 유지비 전무)** | 유료 (API 호출당 비용 발생 또는 GPU 서버 유지비) |
| **채보 정확도** | 단선율 허밍 기준 준수 (90% 이상) | 다성 음악/배경 소음에 강건 |
| **구현 복잡도** | 자체 DSP 알고리즘 정밀 튜닝 필요 | API 클라이언트 연동으로 단순 |

**최종 기술 채택**: 
우리 아이 칼림바 음악 교실은 PWA 오프라인 지원과 어린이 개인정보 보호가 최우선이므로, **방안 A(브라우저 로컬 고정밀 YIN + 에너지 세그멘테이션 DSP)**를 기본 엔진으로 구축하고, 어린이가 오인된 음을 손쉽게 터치하여 바꿀 수 있는 **인터랙티브 검토 UI(`HummingTranscriptionModal`)**를 결합하는 하이브리드 전략을 채택합니다.

## 4. 4단계 허밍 채보 파이프라인 설계

```
[ 마이크 허밍 녹음 (Float32Array PCM) ]
                   │
                   ▼
[ 1단계: F0 피치 추정 (YIN / Difference Function) ]
  - 2048 샘플 프레임, 512 샘플 홉
  - F0 (Hz) 산출 및 MIDI 번호 변환 (m = 69 + 12*log2(f/440))
  - 센트(Cent) 편차 및 주기성 신뢰도(Confidence) 측정
                   │
                   ▼
[ 2단계: 음표 구간 분할 (Onset/Offset Segmentation) ]
  - RMS 에너지 급상승(Envelope Attack) 및 무음(Silence) 검출
  - 연속된 프레임 간 피치 안정도(±0.8 반음 이내 유지) 병합
  - 최소 음표 길이(80ms) 미만의 노이즈 글리치 제거
                   │
                   ▼
[ 3단계: 리듬 양자화 (Rhythm Quantization) ]
  - 음표 지속 시간(ms) 측정 및 템포(BPM) 기반 비트 변환
  - 8분음표(0.5박), 4분음표(1.0박), 점4분(1.5박), 2분음표(2.0박) 등 표준 음길이로 스냅
                   │
                   ▼
[ 4단계: 17음 칼림바 매핑 & 옥타브 보정 (Kalimba Mapping) ]
  - 음역 이탈 감지: C4(60) 미만 저음 허밍 시 전체 +12(옥타브 상향) 자동 시프트
  - 비장음계 반음(#) 감지 시 가장 가까운 C Major 자연음 매핑 및 주의 플래그 지정
  - 숫자 악보(1, 2, 3...) 및 `Song` 객체 조립
                   │
                   ▼
[ 검토 및 수정 UI (HummingTranscriptionModal) ]
  - 건반 터치 수정, 미리듣기 재생, '내 곡으로 저장'
```
