# 🔍 Kalimba-MC STEP 02-D: 악보 이미지 처리, Canvas 오선 검출 엔진 및 OMR/직접입력 모드 기술 보고서

## 1. 개요
본 문서는 브라우저 클라이언트 환경에서 안전하고 신속하게 악보 이미지를 디코딩하고, 오선(Staff Line)의 위치를 수평 투영(Horizontal Projection) 기법으로 감지하며, 인식 결과에 따라 `OMR_READY`와 `MANUAL_ENTRY_MODE`를 정직하고 투명하게 분기하는 기술적 구조를 설명합니다.

---

## 2. 이미지 검증 및 메모리 생명주기 관리

### 1) 다계층 파일 검증
1. **파일 크기**: $15 \times 1024 \times 1024$ 바이트(15MB) 상한선 검사.
2. **MIME 타입**: `image/png`, `image/jpeg`, `image/jpg`, `image/webp` 4종 허용. (스크립트 삽입 위험이 있는 `image/svg+xml` 및 무거운 `application/pdf`는 차단).
3. **디코딩 및 해상도**: `Image()` 객체 로드를 통해 가로·세로 각 4096px 이하인지 검사.

### 2) Blob URL 수명 관리
- 업로드 시 `URL.createObjectURL(file)`을 생성하여 뷰어 및 Canvas 렌더링에 사용.
- 이미지 교체나 화면 퇴장(`useEffect` 클린업) 시 `URL.revokeObjectURL(imageUrl)`을 즉시 호출하여 브라우저 가비지 컬렉터가 메모리를 회수할 수 있도록 보장.

## 3. Canvas 기반 오선(Staff Line) 검출 휴리스틱

```mermaid
flowchart LR
    A["원본 이미지"] --> B["Canvas 800px 리스케일링"]
    B --> C["이진화 임계값<br/>(Brightness < 140)"]
    C --> D["수평 투영 배열<br/>(rowDarkness[y])"]
    D --> E["피크 검출<br/>(가로 35% 이상 검은 선)"]
    E --> F["5개 줄 클러스터링<br/>(간격 6~55px)"]
    F --> G["DetectedStaffSystem[]"]
```

### 1) 수평 투영(Horizontal Projection) 알고리즘
오선은 악보 가로 전체에 걸쳐 있는 얇은 검은색 직선입니다.
따라서 이미지의 각 행($y$)마다 어두운 픽셀 비율($D_y$)을 계산합니다:
$$D_y = \frac{1}{W} \sum_{x=0}^{W-1} \mathbb{I}(\text{brightness}(x, y) < 140)$$

여기서 $D_y \ge 0.35$이고 주변 행보다 높은 피크를 오선 후보선으로 추출합니다.

### 2) 5개 줄 클러스터링
- 연속된 후보선 간격 $\Delta y = y_{i} - y_{i-1}$이 $6\text{px} \le \Delta y \le 55\text{px}$인 5개의 선을 묶어 하나의 오선 시스템(`DetectedStaffSystem`)으로 확정합니다.
- 오선의 상단(`yTop`), 하단(`yBottom`), 평균 오선 간격(`lineSpacing`)을 계산하여 원본 이미지 뷰어의 오버레이 가이드 박스로 렌더링합니다.

## 4. OMR 상태 머신 및 동작 모드 분기

| 상태 코드 | 조건 | 사용자 인터페이스 표시 | 동작 모드 |
| :--- | :--- | :--- | :--- |
| `ANALYZING` | 이미지 로드 직후 | "악보 이미지와 오선 패턴을 분석하는 중입니다..." | 로딩 스피너 |
| `OMR_READY` | 유효한 오선 묶음 1개 이상 감지 | `[✨ OMR 자동 인식 완료]` (초록색 배지) | 감지된 오선 영역에 기반한 악보 템플릿 로드 |
| `MANUAL_ENTRY_MODE` | 오선 패턴 불명확 (손그림 등) | `[✏️ 스마트 직접 입력 모드]` (주황색 배지) | 악보를 보며 17음 건반으로 손쉽게 직접 입력 |
| `ERROR` | 이미지 디코딩 실패 / 규격 초과 | 한국어 오류 메시지 및 재시도 안내 | 업로드 화면 유지 |

## 5. 결론
실제 인식되지 않은 악보를 인공적으로 꾸며내는 가짜 기능을 배제하고, Canvas 오선 검출 기술과 사용자의 직관적인 칼림바 건반 팔레트를 결합하여 **누구나 실패 없이 악보를 완성할 수 있는 높은 사용성**을 달성했습니다.
