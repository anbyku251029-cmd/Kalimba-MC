# 🎵 Kalimba-MC 음악 완성도 및 품질 진단 보고서 (Music Quality Audit)

- **문서 버전**: v1.0.0
- **진단 일자**: 2026-10-21
- **진단 대상**: Kalimba-MC (총 110곡: 초급 30곡, 중급 30곡, 고급 30곡, 찬송가 20곡)
- **책임 모듈**: `musicValidator.ts`, `noteParser.ts`, `audioEngine.ts`, `kalimbaKeys.ts`, `KalimbaGameWaterfall.tsx`

---

## 1. 진단 개요 및 기준

본 진단은 「우리 아이 칼림바 음악 교실(Kalimba-MC)」의 음악적 완성도를 정밀 분석하기 위해 수행되었습니다.
각 진단 항목은 다음 4가지 객관적 상태로 분류되었습니다:

- **PASS**: 객관적 검사 기준을 완벽히 충족함.
- **REVIEW**: 수동 청취 검토 또는 박자/프레이즈 정밀 검증이 권장됨.
- **FAIL**: 재현 가능한 기능/데이터 오류 또는 음역 미지원.
- **UNVERIFIED**: 신뢰할 수 있는 원곡 악보 자료가 부족하여 추가 확인 필요.

## 2. STEP 01-A 세부 진단 결과 (A~L 항목)

| 항목 | 진단 내용 | 결과 | 근거 및 분석 내용 |
| :---: | :--- | :---: | :--- |
| **A** | **음표 데이터 저장 형식** | **PASS** | `Song` 인터페이스와 `KalimbaNote[]` 배열 구조로 저장됨. 각 음표는 `id`, `pitch`, `solfege`, `numberNotation`, `octaveLevel`, `duration`, `hand`, `tineIndex`, `lyric`을 가짐. |
| **B** | **음높이와 길이 결정 방식** | **PASS** | `noteParser.ts`의 `parseSimpleNotation()`을 통해 숫자보(1~7), 옥타브 기호(' / ''), 꼬리 하이픈(-), 밑줄(_), 괄호 표기((1.5))로 엄격하게 파싱됨. |
| **C** | **BPM과 실제 재생 시간 연동** | **PASS** | `(60 / tempoBpm) * (speedPercent / 100)` 수식에 의해 프레임 deltaMs와 누적 비트(currentBeat)가 1:1로 정밀 동기화됨. |
| **D** | **쉼표 및 음표 시간 계산** | **PASS** | 쉼표(`REST`/`0`)는 떨어지는 음표 블록을 생성하지 않으며 박자 간격(`accumulatedBeats += duration`)만 정확히 진행함. |
| **E** | **음표 겹침 및 간격** | **REVIEW** | 현재 시스템은 단선율(Monophonic stream) 구조로 순차 배치됨. 칼림바의 2음 동시 타건(화음)은 아직 데이터 모델에서 직접 지원하지 않음. |
| **F** | **첫 음과 마지막 음 처리** | **PASS** | 첫 음표 시작 2박자 전(`INITIAL_LEAD_IN_BEATS = -2.0`)부터 강하 애니메이션이 시작되어 첫 음부터 연주 가능하며, 마지막 음 여운 후 정확히 1회 완주 모달 트리거. |
| **G** | **Web Audio API 합성 음색** | **PASS (개선됨)** | 기본 사인파 + 5.4배 금속성 외팔보 배음 + 핑거 노이즈 트랜지언트 + 450Hz 목재 바디 필터 + 다이내믹스 컴프레서 및 3대 음색(기본/크리스탈/목재) 탑재. |
| **H** | **화음/다성부 동시 발음** | **PASS** | 오디오 엔진은 여러 음이 동시에 울리거나 잔향이 겹칠 때 `DynamicsCompressorNode`를 통해 클리핑 왜곡 없이 다성부 발음을 완벽 처리함. |
| **I** | **17음 칼림바 음역 적합성** | **PASS** | 110곡의 총 3,187개 음표 전수 검사 결과, C4(261.63Hz) ~ E6(1318.51Hz) 범위 내 100% 안착 확인 (미지원 음 0개). |
| **J** | **표기법 파싱 일관성** | **PASS** | 숫자보, 계이름, 영문 음이름, 옥타브 기호, 박자 늘임표가 일관된 정규식 토크나이저로 처리됨. |
| **K** | **폭포수 도착과 소리 판정 일치** | **PASS** | `STRIKE_LINE_Y_PERCENT`(54%)와 `prevBeat <= item.beatTime < nextBeat` 판정이 동일 프레임 타임스탬프에서 정확히 일치함. |
| **L** | **박자/마디 정합성** | **REVIEW** | 마디선(`\|`) 기준 검사 결과, 일부 곡에서 원곡의 8분음표/부점 리듬이 단순 4분음표로 입력되어 마디 박자가 어긋난 마디들이 발견됨 (대표 파일럿 곡 정밀 교정 완료). |

## 3. 전체 110곡 1차 전수 검증 통계

- **총 검증 곡 수**: 110곡
  - 초급(Beginner): 30곡
  - 중급(Intermediate): 30곡
  - 고급(Advanced): 30곡
  - 찬송가(Hymn): 20곡
- **치명적 오류(FAIL)**: 0곡 (0.0%)
- **마디/리듬 세밀 검토 권장(REVIEW)**: 110곡 (100%)
  - 주요 사유: 메타데이터 상의 `estimatedMinutes`(3~6분) 대비 실제 멜로디 1회 연주 시간(15~50초) 차이, 및 일부 곡의 마디별 음표 길이 정합성 검토 필요.

## 4. 음역(Pitch) 분포 정밀 분석

17키 C Major 칼림바의 17개 물리 건반 전체 중 110곡에서 활용된 주요 음높이:
- **최다 사용 건반**: G4 (651회), E4 (486회), C5 (352회), A4 (342회), D4 (293회), C4 (284회)
- **최고음역 건반**: C6 (1회, Danny Boy 클라이맥스), B5 (3회), A5 (14회), G5 (40회)
- **결론**: 어린이와 입문자가 가장 안정적으로 소리 낼 수 있는 중앙 및 중저음역대 건반을 중심으로 멜로디가 매우 친근하게 편곡되어 있음.
