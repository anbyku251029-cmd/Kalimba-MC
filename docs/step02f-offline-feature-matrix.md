# 📋 Kalimba-MC STEP 02-F: 기능별 오프라인 지원 여부 매트릭스 (Feature Matrix)

## 1. 개요
본 문서는 인터넷 연결이 완전히 차단된 비행기 모드나 오프라인 환경에서 Kalimba-MC의 각 기능별 실제 지원 여부와 동작 방식을 명확히 규정합니다.

---

## 2. 오프라인 기능 지원 매트릭스

| 기능 영역 | 오프라인 지원 여부 | 세부 동작 방식 및 자립성 원리 | 사용자 안내 |
| :--- | :---: | :--- | :--- |
| **앱 실행 및 새로고침** | **✅ 완전 지원** | Service Worker가 캐시된 `index.html`과 JS 번들을 반환하여 즉시 앱 구동 | 상단에 오프라인 모드 안내 배너 표시 |
| **17음 가상 칼림바 연주** | **✅ 완전 지원** | 외부 사운드 다운로드 없이 `Web Audio API` 오실레이터와 배음 합성으로 100% 로컬 생성 | 17건반 맑은 소리 즉시 출력 |
| **기본 수록곡 111곡 연주** | **✅ 완전 지원** | 초급(30), 중급(30), 고급(30), 찬송가(21) 악보 데이터가 앱 번들 내장 | 워터폴 게임 100% 정상 연주 |
| **마디 구간 연습 모듈** | **✅ 완전 지원** | 로컬 악보 파서(`measureParser.ts`) 기반으로 오프라인 구간 반복 실행 | 100% 정상 동작 |
| **리듬 판정 및 콤보 엔진** | **✅ 완전 지원** | 단조 증가 타이밍 기반으로 오프라인 완벽 판정 | PERFECT, GREAT, 콤보 이펙트 정상 |
| **구구가가 캐릭터 반응** | **✅ 완전 지원** | 로컬 CSS 키프레임 및 React 상태 머신으로 동작 | 5단계 표정 및 애니메이션 정상 |
| **구구가가 스티커 보상판** | **✅ 완전 지원** | `localStorage`에 완주 횟수 및 스티커 보상 즉시 기록 | 스티커 10종 해금 정상 |
| **어린이 연주 녹음 스튜디오** | **✅ 완전 지원** | `OfflineAudioContext`로 오프라인 렌더링 후 순수 JS로 16-bit WAV 파일 다운로드 | 컴퓨터/스마트폰에 로컬 저장 |
| **악보 이미지 수동 편집** | **✅ 완전 지원** | 이미지 파일 로컬 로드, 17음 칼림바 건반 팔레트 입력 및 미리듣기 지원 | 100% 정상 동작 |
| **악보 이미지 Canvas 오선 감지**| **✅ 완전 지원** | 브라우저 내장 Canvas 픽셀 분석(수평 투영)으로 로컬에서 감지 | 오선 가이드 박스 표시 |
| **학습 기록 및 대시보드** | **✅ 완전 지원** | `learningSessionManager`가 `localStorage`에 초 단위 정밀 기록 및 7일 차트 렌더링 | 오프라인에서 누적 기록 유지 |
| **CSV / JSON 내보내기** | **✅ 완전 지원** | Blob 생성 및 로컬 파일 다운로드 | 오프라인 즉시 다운로드 |
| **Web Speech 한국어 TTS** | **⚠️ 기기 의존** | OS(Windows, Android, iOS)에 한국어 음성 팩이 내장된 경우에만 소리 출력 | 미지원 기기에서는 텍스트 안내로 자동 대체 |
| **외부 클라우드 서버 동기화** | **❌ 미지원** | 현재 버전은 프런트엔드 독립형이므로 서버 동기화 미제공 | 로컬 스토리지에 안전 보존됨을 안내 |
