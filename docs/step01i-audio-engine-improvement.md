# STEP 01-I: 칼림바 오디오 엔진 전문 개선 보고서

**프로젝트명**: 우리 아이 칼림바 음악 교실 (Kalimba-MC)  
**작성일**: 2026-10-24  
**기술 스택**: Web Audio API, TypeScript, React 19, Tailwind CSS v4  

---

## 1. 개요

본 보고서는 Web Audio API를 활용하여 17음 C Major 칼림바의 물리적 음향 특성과 음악적 표현력을 대폭 향상시킨 기술 구현 내역을 기술합니다.

외부 음원 파일이나 고용량 샘플러에 의존하지 않고, 브라우저 표준 Web Audio 노드(Oscillator, Gain, BiquadFilter, Delay, BufferSource)만을 조합하여 가볍고 즉각적이며 아름다운 칼림바 소리를 완성하였습니다.

---

## 2. 주요 개선 사항

### 2.1 4단계 하이브리드 음향 합성 아키텍처
각 음표가 발음될 때 다음 4개의 음향 체인이 유기적으로 결합되어 소리를 생성합니다:

1. **기음 오실레이터 (Fundamental Sine)**:
   - 각 건반의 정확한 기본 주파수(C4 261.63Hz ~ E6 1318.51Hz) 발진.
   - 탄현 직후 쇠막대의 마이크로 텐션 변화를 반영하는 **피치 벤딩(Pitch Deflection)** 적용 (저음 1.012배, 고음 1.004배에서 0.01초 내 원음으로 수렴).
2. **비조화 고차 금속 배음 (Inharmonic Metallic Overtone ~5.4x)**:
   - 칼림바 쇠막대(Clamped-free bar) 고유 진동 모드인 5.4배 배음을 독립 발진.
   - 나이퀴스트 리밋(sampleRate / 2)을 초과하지 않도록 안전 필터링 적용.
3. **손톱 탄현 트랜지언트 노이즈 (Pluck Transient Noise)**:
   - 감쇠형 백색 잡음 버퍼(BufferSource)를 0.016초간 생성하여 밴드패스 필터(2500~3800Hz)를 통과시켜, 손톱이나 골무가 쇠막대를 긁고 튕기는 순간의 선명한 타격감을 시뮬레이션.
4. **우든 사운드박스 공명 (Wooden Cavity Resonator)**:
   - 420~450Hz 피킹 필터(Q: 1.8~2.4, Gain: +3.2~+4.2dB)를 통해 가상 목재 울림통의 따뜻한 통 공명을 형성.

### 2.2 음역별(Tine Length) 감쇠 곡선 차등화
- **저음역 (C4~G4)**: 쇠막대가 길어 서스테인이 길고 웅장함 (최대 2.5초 지수 감쇠).
- **중음역 (A4~B5)**: 명료하고 균형 잡힌 서스테인 (1.2~1.8초 감쇠).
- **고음역 (C6~E6)**: 쇠막대가 짧아 서스테인이 짧고 청아함 (0.6~0.9초 감쇠).

## 3. 마디 내 음악적 강약(Dynamic Accent) 알고리즘

기존의 평면적인 메트로놈식 연주를 탈피하기 위해 박자표별 마디 내 박자 위치(`beatInMeasure`)에 따라 동적 벨로시티를 자동 산출하는 순수 함수 `calculateDynamicAccent`를 구현하였습니다.

```typescript
// 4/4 박자: 강(1박 1.0) -> 약(2박 0.74) -> 중강(3박 0.88) -> 약(4박 0.72)
// 3/4 박자: 강(1박 1.0) -> 약(2박 0.72) -> 약(3박 0.70)
// 2/4 박자: 강(1박 1.0) -> 약(2박 0.74)
// 6/8 박자: 강(1박 1.0) -> 중강(4박 0.86) -> 약(기타 0.70)
```

이 강약 계수가 `musicTiming.ts` 타임라인 계산 시 모든 음표에 자동 부여되며, `KalimbaGameWaterfall`에서 타격선에 도달할 때 오디오 엔진의 어택 게인과 노이즈 레벨에 반영되어 살아있는 리듬감을 만들어냅니다.

## 4. 한국어 친화형 3대 음색 프리셋

| 프리셋 ID | UI 표시 명칭 | 음향적 특성 및 최적 용도 |
|:---:|:---:|:---|
| `clean` | **맑은 소리** | 음표 하나하나가 맑고 또렷하게 분리되어 처음 배우는 아이에게 가장 알맞은 학습용 음색 |
| `warm` | **따뜻한 소리** | 450Hz 목재 공명을 강조하고 날카로운 고음을 다듬은 포근한 감상용 음색 |
| `expressive` | **풍성한 연주** | 마디별 강약 다이내믹스와 콘서트홀 잔향(Send +33%)을 살린 생동감 넘치는 연주 음색 |
