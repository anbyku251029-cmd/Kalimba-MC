## 1. 작업 개요

STEP 01-D에서는 기존의 단순 합성음 수준에 머물렀던 Web Audio API 사운드를 **실제 17음 C Major 칼림바의 어쿠스틱 물리적 울림(금속 틴 타격감 + 고차 배음 + 우든 울림통 공명 + 자연스러운 감쇠)**에 가깝도록 정밀 모델링하고,
악보의 박자·BPM·음표 길이·폭포수 애니메이션 타격선 도달 시점 및 완주 모달 표시 시점이 **단일 기준(Single Source of Truth)으로 정확히 일치**하도록 재생 엔진과 타이밍 체계를 전면 개선하였습니다.

## 2. STEP 01-C와의 연결 및 음역 매핑 상태

- **17음 C Major 칼림바 조율 보존:** `C4(261.63Hz)`부터 `E6(1318.51Hz)`까지 17개 물리 건반의 주파수 및 좌우 대칭 배열(`KALIMBA_KEYS`, `PITCH_TO_KEY`)을 100% 그대로 유지하였습니다.
- **음역 이탈 0건:** 110곡의 음표 데이터에서 임의의 옥타브 이동이나 주파수 변경 없이 원본 조율을 엄격히 준수하였습니다.

## 4. 음색 개선 방식 (Acoustic Kalimba Synthesis)

실제 칼림바 녹음 음원을 직접 사용하지 않는 Web Audio API 순수 합성 환경에서 악기의 물리적 특성을 최대한 근사하기 위해 다음과 같은 6단계 사운드 체인을 구현하였습니다:

1. **기음 오실레이터 (Fundamental Sine Body):**
   - 맑고 따뜻한 정현파를 기반으로 하되, 쇠막대를 손톱으로 튕기는 찰나 텐션이 올라갔다 떨어지는 피치 디플렉션(Pitch Deflection)을 저음은 1.014배, 고음은 1.005배로 차등 부여하여 자연스러운 타격 탄성을 재현했습니다.
2. **비조화 고차 배음 (Inharmonic Overtone ~5.4x):**
   - 한쪽 끝이 고정된 외팔보 쇠막대(Clamped-free bar)의 물리적 진동 특성인 5.4배 배음을 합성했습니다.
   - 고음(E5~E6)으로 갈수록 배음 주파수가 7kHz를 넘어 거슬리지 않도록 고음역 배음 게인을 점진적으로 억제하여 맑고 투명한 벨 소리를 구현했습니다.
3. **손톱 탄현 어택 트랜지언트 (Pluck Noise Buffer):**
   - 0.01~0.02초 길이의 감쇠형 백색 잡음 버퍼를 대역통과 필터(Bandpass Filter)로 걸러 손톱이나 골무가 쇠막대를 긁고 튕겨나가는 미세한 마찰음을 시뮬레이션했습니다.
4. **우든 바디 울림통 공명 (Wooden Soundbox Resonator):**
   - 나무 울림통의 내부 공명 주파수인 430~460Hz 피킹 필터(Peaking Filter)를 장착하여 중저음역(C4~G4)에서 칼림바 특유의 나무통 공명감을 풍성하게 부가했습니다.
5. **음높이에 따른 물리적 감쇠 시간 차등화:**
   - 저음 틴(C4): 최대 2.2~2.4초 서스테인
   - 고음 틴(E6): 0.65~0.75초의 짧고 경쾌한 감쇠
6. **클리핑 및 음량 합산 방지:**
   - 다이내믹 컴프레서(`DynamicsCompressorNode`, -12dB threshold, 4:1 ratio)를 거쳐 빠른 연주나 화음 발생 시에도 스피커 찢어짐을 완벽 차단했습니다.

## 5. 단일 기준 공통 타이밍 계산 체계 (`musicTiming.ts`)

BPM과 음표 길이를 계산하는 기준을 하나의 공통 모듈로 단일화하였습니다:

- **1박 기준 초(Seconds):** `(60 / tempoBpm) * (100 / speedPercent)`
- **음표 길이 체계:**
  - 4분음표 = 1.0박
  - 2분음표 / 늘임표(`-`) = 2.0박
  - 점2분음표(`--`) = 3.0박
  - 8분음표(`_`) = 0.5박
  - 16분음표 = 0.25박
- **예비박 동기화:** `INITIAL_LEAD_IN_BEATS = -2.0` (연습 시작 시 2박자 동안 첫 음이 위에서 타격선으로 자연스럽게 하강)
- **완주 시점 일치:** 악보 상의 마지막 음표 종료 비트(`musicalEndBeat`)에 마지막 음의 여운 대기 시간(`tailSustainBeats`)을 더한 `audibleEndBeat`를 완주 기준으로 설정하여 소리가 끝나기 전에 모달이 뜨거나, 여운 없이 뚝 끊기는 현상을 원천 방지했습니다.

## 6. 오디오 자원 관리 및 일시정지·재시작 안정성

- **AudioContext 싱글톤:** 컨텍스트의 불필요한 반복 생성을 방지하고, 브라우저 사용자 제스처 정책(Autoplay Policy)에 맞춰 안전하게 재개(`resume`)되도록 관리합니다.
- **활성 보이스 추적 및 즉각 소거 (`stopAll`):**
  - 발음 중이거나 미래 예약된 음표의 오실레이터와 게인 노드를 `activeVoices` 배열로 추적합니다.
  - 일시정지, 처음부터 재시작, 곡 변경, 연습 종료 시 `audioEngine.stopAll()`을 호출하여 0.018초 내에 부드럽게 페이드아웃 후 노드를 정리함으로써 찌꺼기 소리나 예약 누수를 방지합니다.

## 9. 실제 칼림바 음색과의 차이 및 솔직한 한계 명시

- **실제 악기와의 차이:**
  - 실제 칼림바는 나무 울림통의 나뭇결, 쇠막대 끝의 손가락 지문 접촉면적, 연주자의 타현 각도 및 옥타브 간의 복잡한 물리적 간섭(Beat frequency)이 존재합니다.
  - 현재 시스템은 순수 Web Audio API 오실레이터와 노이즈 필터링으로 합성한 결과물이므로, 실제 고음질 마이크로 녹음한 샘플링 음원과 비교할 때 미세한 배음의 유기적 불규칙성에는 한계가 있습니다.
- **장점:**
  - 별도의 대용량 오디오 파일 다운로드 없이 0.1초 만에 즉시 로딩되며, 네트워크 환경에 구애받지 않고 언제 어디서나 가볍고 빠른 반응 속도로 실행됩니다.
