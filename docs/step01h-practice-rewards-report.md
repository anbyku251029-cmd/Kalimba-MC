## 1. 개요 및 목적

어린이(특히 미취학 유아 및 초등 저학년)가 칼림바를 배울 때 곡 전체를 처음부터 끝까지 연주하는 것은 집중력과 손가락 소근육 발달 측면에서 큰 도전이 될 수 있습니다.

STEP 01-G에서 구현된 **마디 범위 선택형 구간 연습(1~4마디, 5~8마디 등)**을 실제로 아이들이 꾸준히 반복할 수 있도록, 사용자의 특별 요청에 따라 **10종의 사랑스러운 "구구가가(GuGuGaGa)" 캐릭터 스티커 수집 및 보상판 시스템**을 구축하였습니다.

아이들이 어려운 마디를 3회, 5회, 10회씩 끈기 있게 완주할 때마다 새로운 구구가가 친구 스티커가 팡파레와 함께 해금되며, 한국어 음성 나레이션으로 칭찬과 축하를 건네어 자연스러운 내적 동기를 유발합니다.

## 3. 핵심 설계 및 기술 구현

### 3.1 독립 전용 스토리지 키 격리
- **스토리지 키**: `kalimba-mc-practice-rewards-v1`
- **보호 원칙**: 기존 찬송가 사용자 등록 데이터(`custom_hymns_v1`) 및 단계별 학습 기록(`kalimba_learning_progress_v1`)에 일절 침범하거나 키 이름을 공유하지 않도록 완벽히 격리하였습니다.
- **데이터 스키마**:
  ```typescript
  interface UserPracticeRewardsData {
    version: 1;
    totalSectionCompletions: number; // 전체 마디 연습 완주 횟수 누적
    unlockedStickerIds: string[]; // ['gugugaga_01', 'gugugaga_02', ...]
    stickerUnlockedDates: Record<string, number>; // 스티커 획득 일시 (ms)
    sectionRecords: Record<string, SectionPracticeRecord>; // 곡 및 마디별 세부 기록
    lastUpdated: number;
  }
  ```

### 3.2 정직한 완주 검증 및 중도 취소 방어
- 마디 구간 재생이 시작되기만 하거나 중간에 멈춤(`stopAllAudio`), 모달 닫기, 페이지 이탈이 일어날 경우 완주로 간주하지 않습니다.
- 선택한 마디 구간(1회, 3회, 5회 반복)의 마지막 음표와 호흡 시간까지 완벽하게 소리가 끝났을 때 발동하는 `finishTimer` 내부에서만 `recordSectionPracticeCompletion`이 호출됩니다.
- 이미 해금된 스티커 ID는 중복 등록되지 않으며, 정확히 새로 해금된 스티커만 배열(`newlyUnlockedStickers`)로 반환합니다.

### 3.3 아동 중심 보상판 UI/UX (`StickerRewardBoardModal`)
- **시각적 상태 대비**:
  - 해금된 스티커: 밝고 고운 그라데이션, 반짝이는 별빛 효과, 선명한 이모지 캐릭터, 획득 완료 뱃지 표시.
  - 미해금 스티커: 은은한 실루엣 음영 처리, 자물쇠 아이콘, 남은 완주 횟수 안내 ("3회 더 연습하면 열려요!").
- **진행률 게이지**: 10개 중 몇 개를 모았는지 한눈에 알 수 있는 무지개 빛깔 진행률 바 제공.
- **음성 나레이션 연동**: 스티커 카드를 누르면 캐릭터 이름과 응원 메시지를 다정한 한국어 음성으로 들려줍니다.
- **접근 경로 다각화**:
  1. `StepLearningModal` 상단 헤더의 `🎨 스티커 보상판` 버튼
  2. `SongSelectScreen` 메인 화면 상단 헤더의 `🎨 구구가가 스티커 보상판` 버튼
  3. 마디 완주로 새 스티커가 해금되는 순간 자동 팝업 및 축하 나레이션 재생
