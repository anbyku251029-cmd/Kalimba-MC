## 1. 개요 및 구현 목표

곡을 끝까지 완주했을 때 어린이에게 풍성한 성취감을 제공하기 위해 **완주 통계 요약 카드**, **구구가가 10종 스티커 보상 연동**, **찬송가 반복 루프 완주 처리**를 구현하였습니다.

- **완주 결과 통계**:
  - `최고 콤보`: 이번 곡 연주 중 기록한 최대 연속 성공 횟수
  - `정확도 %`: 완벽/좋음 판정에 기반한 최종 연주 정확도
  - `성공 음표 수`: 전체 음표 중 성공적으로 튕긴 음표 수
- **기존 스티커 보상(`practiceRewardService.ts`)과 100% 연동**:
  - 완주 시 `recordSectionPracticeCompletion(songId, 1, 999)`를 호출하여 마디 완주 카운트 자동 증가
  - 3회, 5회, 8회, 10회 등 마일스톤 달성 시 해금된 신규 스티커(`newlyUnlockedStickers`)를 완주 모달 상단에 축하 배지로 표시
  - 중복 지급 방지: 동일 세션에서 단 1회만 지급
- **찬송가 반복 재생 안전성**:
  - 3~4회 반복 묵상 연주 시 중간 회차(1회차, 2회차)에는 완주 모달이 뜨지 않고 다음 회차로 매끄럽게 연결되며, **최종 목표 회차(예: 3회차)가 모두 끝났을 때만 완주 모달이 표시**됩니다.
