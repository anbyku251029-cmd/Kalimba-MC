## 2. 세부 문제 분석 및 실제 수정 내역

### [ISSUE-01] C6 건반 옥타브 점 표기 오류
- **발견 위치:** `src/constants/kalimbaKeys.ts` (index 15)
- **증상 및 재현 방법:**
  - 17키 칼림바에서 index 15번 건반은 `C6` (가운데 도에서 2옥타브 위)입니다.
  - 건반 그래픽 렌더링 시 D6(index 0)과 E6(index 16)은 위에 두 점(`:`)이 표시되는데, C6만 점 1개(`•`)가 표시되어 1옥타브 높은 도(C5)와 시각적으로 혼동되는 문제가 있었습니다.
- **원인 분석:**
  - `octaveLevel: 2`로 올바르게 설정되어 있었으나, `dots: 1`로 오입력되어 있었습니다.
- **수정 내용:**
  - `dots: 1`을 `dots: 2`로 수정하여 건반 그래픽과 악보 상에 두 점(`:`)이 정상 표시되도록 개선했습니다.
```diff
- { index: 15, pitch: 'C6', solfege: '도', numberNotation: '1', octaveLevel: 2, dots: 1, ... }
+ { index: 15, pitch: 'C6', solfege: '도', numberNotation: '1', octaveLevel: 2, dots: 2, ... }
```

### [ISSUE-02] 찬송가 편집기 미리듣기 타이머 누수
- **발견 위치:** `src/components/HymnEditorModal.tsx`
- **증상 및 재현 방법:**
  - '앞부분 미리 듣기'를 누르고 음이 연주되는 도중 '닫기(X)' 또는 '취소'를 누르거나, 다시 '미리 듣기'를 빠르게 여러 번 누르면 이전 예약된 `setTimeout` 음표들이 뒤섞여 계속 재생되는 현상이 발생했습니다.
- **원인 분석:**
  - `previewSlice.forEach` 내부의 `setTimeout` 타이머 핸들을 저장하지 않아 일괄 취소할 수 없었습니다.
- **수정 내용:**
  - `previewTimerRef`를 도입하여 모든 타이머 ID를 배열에 등록하고, 정지/닫기/저장/언마운트 시 `window.clearTimeout` 및 `audioEngine.stopAll()`을 즉각 호출하도록 수정했습니다.
  - 또한 미리듣기 버튼을 토글(`재생/정지`) 방식으로 개편했습니다.

### [ISSUE-03] 찬송가 편집기 최고음(C6~E6) 빠른 입력 지원
- **발견 위치:** `src/components/HymnEditorModal.tsx` (`QUICK_NOTE_BUTTONS`)
- **수정 내용:**
  - 칼림바 17키 중 최고음역인 `7'(높은시)`, `1''(최고도)`, `2''(최고레)`, `3''(최고미)` 및 `0(쉼표)` 단축 버튼을 툴바에 추가하여 마우스 클릭만으로 17키 전 음역의 악보를 손쉽게 편집할 수 있도록 개선했습니다.

### [ISSUE-04] 전체 화면 상하 스크롤 잠금 해제
- **발견 위치:** `src/App.tsx`, `src/components/KalimbaGameWaterfall.tsx`, `src/index.css`
- **증상 및 재현 방법:**
  - 세로 해상도가 낮은 노트북이나 모바일, 브라우저 화면 확대 상태에서 곡 선택 화면의 하단 카드나 연습 화면의 하단 칼림바 건반이 잘리는 현상이 발생했습니다.
- **원인 분석:**
  - 최상위 컨테이너에 `h-screen overflow-hidden`이 걸려 있어 브라우저 세로 스크롤이 원천 차단되어 있었습니다.
- **수정 내용:**
  - `min-h-screen overflow-y-auto overflow-x-hidden` 구조로 전환하고, 테마 맞춤형 세로 스크롤바와 부드러운 스크롤(`smooth scroll`)을 구현하여 마우스 휠 및 터치로 위아래 스크롤을 완벽히 지원했습니다.

## 3. 미해결 문제 및 향후 검토 과제 (REVIEW)

1. **마디별 박자 정밀도 (붓점 및 16분음표 편곡):**
   - 현재 초급 동요 중 '산토끼', '곰 세 마리' 등은 어린이 학습 편의를 위해 붓점(점8분+16분음표)을 균등한 8분음표로 단순화하여 채보된 구간이 있습니다.
   - 이는 칼림바 초보자가 연주하기에는 수월하나, 원곡의 통통 튀는 리듬감과는 차이가 있으므로 다음 STEP에서 신뢰할 수 있는 악보 자료를 기반으로 선별적 리듬 개선을 진행할 예정입니다.
2. **못갖춘마디(Anacrusis) 곡의 표시 마디 계산:**
   - 4/4박자 곡 중 1박자 또는 2박자로 시작하는 못갖춘마디 곡의 경우, 시각적인 마디선 표시와 박자 카운트 계산을 더욱 자연스럽게 연계하는 세부 디스플레이 튜닝이 권장됩니다.
