## 2. 5단계 학습 흐름 (Step-by-step Learning Flow) 설계

어린이가 무작정 폭포수 게임을 시작하여 당황하지 않고, 차근차근 음악을 체득할 수 있도록 5단계 가이드를 설계하고 구현하였습니다.

```mermaid
flowchart LR
    S1["1단계: 먼저 듣기<br>(원곡 감상)"] --> S2["2단계: 건반 익히기<br>(음표-건반 1:1 탐색)"]
    S2 --> S3["3단계: 짧은 구간 연습<br>(앞 2마디 무한 루프)"]
    S3 --> S4["4단계: 곡 전체 연습<br>(폭포수 게임 플레이)"]
    S4 --> S5["5단계: 연습 결과 확인<br>(성취 피드백 및 통계)"]
```

1. **1단계: 먼저 듣기 (`LISTENING`)**
   - 곡의 멜로디를 편안하게 귀로 먼저 듣고 리듬과 분위기를 인지합니다.
   - 앞부분 16음을 부드러운 템포(70%)로 미리 재생하며, 원할 때 언제든 다시 듣거나 멈출 수 있습니다.
   - 격려 문구: *"좋아요! 먼저 노래를 들어 볼까요?"*
2. **2단계: 음표와 건반 익히기 (`KEY_EXPLORE`)**
   - 이 곡에 나오는 음표(도, 레, 미...)를 클릭하면 17음 칼림바 물리 건반에서 어디를 튕겨야 하는지 황금색으로 빛나며 소리가 납니다.
   - 숫자 악보(1, 2, 3)와 계이름, 옥타브 점 표기가 실제 칼림바 건반과 직관적으로 연결됩니다.
   - 격려 문구: *"이제 건반 위치를 확인해 보세요!"*
3. **3단계: 짧은 구간 연습 (`LOOP_PRACTICE`)**
   - 곡 전체를 한 번에 연주하기 어려운 어린이를 위해, 앞 2마디(약 8박자 분량)만 떼어내어 무한 반복 재생합니다.
   - 타이머 누수 없이 루프를 돌며, 어린이가 해당 구간의 손가락 번갈아 치기를 완벽하게 손에 익힐 수 있습니다.
   - 격려 문구: *"천천히 다시 연습해 봐요."*
4. **4단계: 곡 전체 연습 (`FULL_PRACTICE`)**
   - 구간 연습이 끝나면 폭포수 건반 게임 화면으로 이동하여 곡 전체를 처음부터 완주합니다.
   - 추천 연습 템포(70%)가 적용되며, 폭포수 타격선에 맞춰 신나게 칼림바를 연주합니다.
   - 격려 문구: *"이제 곡 전체를 신나게 연주해 봐요!"*
5. **5단계: 연습 결과 확인 (`PRACTICE_RESULT`)**
   - 오늘 완수한 학습 단계 수(1~5단계), 누적 연습 시간, 누적 연습 횟수를 정직하게 표시합니다.
   - 마이크 분석을 사용하지 않은 상태에서 거짓 음정 점수를 매기지 않고, 성실하게 연습한 과정을 칭찬합니다.
   - 격려 문구: *"연습 단계를 완료했어요! 잘하고 있어요. 매일 조금씩 익히면 멋진 칼림바 연주자가 될 거예요!"*

## 3. 어린이 친화적인 피드백 시스템 및 상태 관리

경쟁 압박이나 부정적 평가(낙제, 감점, 오답 표시)를 배제하고, 어린이가 성취감을 느끼고 계속 도전할 수 있도록 따뜻한 한국어 피드백 정책을 수립하였습니다.

### 피드백 상태 머신 (`PracticeFeedbackState`)

| 상태 코드 | 화면 표시 문구 | 상황 설명 |
| :--- | :--- | :--- |
| `PRACTICE_STARTED` | *"신나는 칼림바 연습을 시작해요!"* | 학습 화면 진입 시 |
| `LISTENING_COMPLETED` | *"노래를 잘 들었어요! 이제 건반 위치를 찾아볼까요?"* | 1단계 먼저 듣기 완료 시 |
| `KEY_EXPLORED` | *"건반 위치를 멋지게 확인했어요!"* | 2단계 건반 탐색 완료 시 |
| `SECTION_PRACTICED` | *"짧은 구간을 멋지게 익혔어요! 전체 곡에 도전해 볼까요?"* | 3단계 구간 반복 연습 완료 시 |
| `SONG_PRACTICED` | *"와! 곡 전체를 완주했어요! 정말 대단해요!"* | 4단계 폭포수 완주 시 |
| `PITCH_ANALYSIS_UNAVAILABLE` | *"마이크 없이도 즐겁게 연습할 수 있어요."* | 마이크 미사용 또는 권한 거부 시 |
| `PITCH_ANALYSIS_UNCERTAIN` | *"소리를 확인하는 중이에요. 한 번 더 맑게 튕겨볼까요?"* | 소음 또는 배음 혼선 시 |
| `PITCH_ANALYSIS_CONFIRMED` | *"정확한 건반 소리를 찾았어요!"* | 허용 오차 내 건반 일치 시 |

## 4. 학습 진행 기록 저장 구조 및 데이터 보호

기존 데이터 손상 및 스키마 충돌을 원천 차단하기 위해 **완전히 독립된 로컬스토리지 키**를 사용합니다:

- **기존 사용자 찬송가 키**: `custom_hymns_v1` (절대 보호, 건드리지 않음)
- **기존 완주 별 획득 키**: `kalimba_classroom_progress_v1` (기존 호환성 유지)
- **신규 단계별 학습 기록 키**: `kalimba_learning_progress_v1` (신규 독립 저장소)

### 저장 데이터 스키마 (`LearningProgressItem`)

```typescript
export interface LearningProgressItem {
  songId: string;                   // 곡 식별자
  completedSteps: LearningStep[];   // 완료한 학습 단계 목록 (Set 기반 중복 방지)
  lastStep: LearningStep;           // 마지막으로 수행한 단계
  loopSectionIndex: number;         // 마지막 연습 구간 인덱스
  practiceCount: number;            // 실제 연습 완주 횟수 (정직한 측정)
  practiceDurationSeconds: number;  // 실제 누적 연습 시간(초)
  lastPracticeTimestamp: number;    // 마지막 연습 타임스탬프
  preferredSpeedPercent: number;    // 학습 선호 속도 (70% 또는 100%)
}
```

- **안전성 원칙**: 브라우저 로컬스토리지 입출력 실패 시에도 메모리 기본값을 안전하게 반환하여 프로그램이 절대 중단되지 않습니다.
- **정직성 원칙**: 실제로 연습 단계를 진행하지 않은 횟수를 자동으로 조작하여 늘리지 않습니다.

## 5. 학습 UX 개선 상세 내역

1. **곡 선택 카드에 `[🌱 단계별 학습]` 버튼 추가**
   - 각 곡 카드 하단에 [먼저 듣기], [단계별 학습], [연습 시작하기] 3개 버튼을 조화롭게 배치하여, 어린이가 원클릭으로 5단계 학습 모달을 열 수 있도록 구현.
2. **모달 기반 인터랙티브 학습 화면 (`StepLearningModal.tsx`)**
   - 5개 탭 상단 내비게이션으로 언제든 이전/다음 단계로 자유롭게 이동 가능.
   - 완료한 단계에는 초록색 체크 아이콘(`CheckCircle2`)이 실시간 점등되어 성취감 제공.
3. **17음 건반 시각 가이드 (2단계 건반 익히기)**
   - 미니 17건반 뷰에서 해당 음표 건반이 황금빛으로 발광하고 건반 번호가 강조되어 어린이의 공간 지각력 향상.
4. **접근성 및 반응형 레이아웃**
   - 모바일, 태블릿, 데스크톱의 작은 화면에서도 스크롤 및 터치가 원활하도록 패딩과 폰트 크기 최적화.

## 8. 미해결 문제 및 향후 과제

- 곡의 후반부 마디(9~16마디 등)를 어린이가 직접 슬라이더로 골라 구간 연습할 수 있는 마디 선택기 UI는 다음 단계에서 고도화 가능.
- 5~6세 유아를 위한 음성 나레이션(TTS) 가이드 추가 검토.
