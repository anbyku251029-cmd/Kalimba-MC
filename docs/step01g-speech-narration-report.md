## 2. Web Speech API 지원 여부 감지 및 대체 전략

1. **안전한 브라우저 지원 감지 (`isSupported()`)**
   - `typeof window !== 'undefined' && 'speechSynthesis' in window`를 검사하여 지원 여부 판별.
   - Chrome, Edge, Safari 등 대부분의 모던 웹 브라우저에서 기본 제공됨.
2. **미지원 브라우저 및 오류 시 대체 전략**
   - API가 지원되지 않는 환경이더라도 프로그램이 결코 에러로 멈추지 않음.
   - 모달 하단에 예쁜 **말풍선 텍스트 자막**(`🗣️ 선생님 음성 안내: "..."`)을 항상 동시 노출하여, 음성을 들을 수 없는 환경이나 청각 보조가 필요한 어린이도 직관적으로 안내를 확인 가능.
   - "음성 안내를 사용할 수 없어. 화면의 안내를 보고 계속 연습할 수 있어." 안내 제공.

## 3. 한국어 음성(ko-KR) 자동 탐색 및 음성 파라미터

- **음성 탐색 로직**:
  - `window.speechSynthesis.getVoices()` 목록 중 `lang === 'ko-KR'` 또는 `lang.startsWith('ko')`인 한국어 음성을 자동 탐색하여 1순위로 바인딩.
  - 브라우저 비동기 음성 로딩 이벤트인 `onvoiceschanged`를 리스닝하여 늦게 로딩되는 시스템 음성도 누락 없이 바인딩.
- **유아 친화적 음향 파라미터**:
  - **말하기 속도 (`rate: 0.85`)**: 어린이가 문장을 또박또박 이해할 수 있도록 기본 속도보다 약 15% 느리게 설정.
  - **음성 피치 (`pitch: 1.05`)**: 다정하고 밝은 동화 구연 톤 적용.
  - **음량 (`volume: 0.9`)**: 칼림바 악기 소리와 조화를 이루는 적정 음량 유지.

## 5. 중복 발화 및 음성 큐 적체 방지 설계

학습 단계를 빠르게 탭하거나 버튼을 연타할 때 음성이 밀려 연속으로 시끄럽게 발화되는 문제를 원천 해결하였습니다:

1. **신규 발화 시 이전 발화 즉시 취소 (`synth.cancel()`)**
   - 새로운 단계로 이동하거나 새 문구가 요청되면 큐에 쌓여 있던 이전 음성을 즉시 중단하고 새 문구를 발화.
2. **동일 문구 2초 디바운스 필터**
   - 같은 문구가 2초 내에 연속 호출될 경우 중복 발화를 자동 차단.
3. **사용자 강제 다시 듣기 (`replayLast()`)**
   - 사용자가 [다시 듣기] 버튼을 직접 눌렀을 때는 디바운스를 우회하여 즉시 다시 들려줌.
4. **컴포넌트 종료 시 리소스 정리**
   - 모달 닫기(`onClose`) 또는 언마운트 시 `speechNarrator.stop()`을 호출하여 백그라운드 발화 완벽 차단.

## 6. 음악 오디오 타이밍과의 완전한 분리

- **원칙**: 음성 나레이션은 **완전한 비동기 fire-and-forget** 방식으로 실행됩니다.
- 음성 엔진의 준비 지연이나 발화 시간 때문에 Web Audio API의 칼림바 재생 시작 시각이 결코 지연되지 않습니다.
- 음성 안내 도중에도 사용자는 칼림바 건반을 치거나 재생을 멈출 수 있으며, 서로 간섭하지 않습니다.
