## 1. 재구축 배경 및 목표

기존 기본 제공 찬송가 20곡은 선율의 일부(첫 1~2마디)만 수록되어 있어, 실제 찬송가의 절(Verse)과 후렴(Chorus)의 은혜로운 멜로디 흐름을 온전히 연주하기 어려웠습니다.

이번 재구축을 통해 다음과 같은 음악적 목표를 달성하였습니다:
1. **정식 찬송가 선율 구조 반영**: 모든 찬송가를 실제 악보 기준 1절 전체 또는 후렴을 포함한 완성도 높은 멜로디로 재편곡
2. **17음 C장조 칼림바 음역 최적화**: C4부터 E6까지의 17개 건반 음역을 벗어나지 않도록 C Major 조옮김 및 정밀 음정 검증
3. **3~4회 반복 묵상 연주 엔진 구현**: 찬송가의 특성인 '반복 묵상'을 위해 기본 3회(선택 시 1회/3회/4회) 순환 연주 기능 및 워터폴 게임 엔진 연동
4. **사용자 찬송가 기능 100% 보존**: 로컬 스토리지(`kalimba_custom_hymns_v1`)에 저장된 사용자 추가/수정 찬송가 데이터와 완벽 격리 호환
