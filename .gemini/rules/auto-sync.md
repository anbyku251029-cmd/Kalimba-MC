# GitHub 자동 동기화 및 완전 자동화 규칙

1. **GitHub 자동 업데이트 원칙**:
   - 코드, 악보, 문서 등 워크스페이스에 변경 사항이 발생할 때마다 별도의 추가 요청을 기다리지 않고, 검증 완료 후 즉시 원격 저장소(`https://github.com/anbyku251029-cmd/Kalimba-MC.git`, 브랜치: `main`)로 자동 `git commit` 및 `git push origin main`을 수행합니다.
   - 커밋 메시지는 한국어로 알기 쉽게 작업 내역을 명시합니다.

2. **완전 자동화 (Submit/확인 질의 금지)**:
   - 사용자가 추가 확인을 누를 필요가 없도록 `ask_question` 도구를 일체 호출하지 않으며, 항상 최적의 구현과 테스트를 자체 완결적으로 실행합니다.

3. **한국어 설명 원칙**:
   - 모든 보고서, 문서, 설명은 한국어로 쉽고 친절하게 작성합니다.
